\begin{frame}
\begin{center}
  {\Large\bfseries\color{deepblue} A coding agent}\\[2pt]
  {\color{accent}\rule{0.28\linewidth}{1.1pt}}
\end{center}

\vspace{0.4em}
\begin{plainbox}
A program that writes and runs code to carry out a request. In AppWorld, a language model writes the next Python code.
\end{plainbox}
\end{frame}

\begin{frame}
\vspace*{-4pt}
\begin{center}
  {\Large\bfseries\color{deepblue} The world and the dataset}\\[1pt]
  {\color{accent}\rule{0.32\linewidth}{1.1pt}}
\end{center}

\vspace{0.12em}
\begin{columns}[T]
\begin{column}{0.49\textwidth}
\begin{stepbox}{The world}
\raggedright
About 100 people. Their accounts, contacts, messages, and payments are already there before the agent starts.

\vspace{0.15em}
Nine apps: Gmail, Venmo, Phone, Spotify, Amazon, Todoist, Splitwise, Simple Note, and a file system. A function is one Python call on an app, such as listing payments. There are 457.
\end{stepbox}
\end{column}
\begin{column}{0.49\textwidth}
\begin{stepbox}{The dataset}
\raggedright
One task is one request from one person.

\vspace{0.3em}
It includes the request, that person's starting world, and tests that check whether the request was carried out.
\end{stepbox}

\vspace{0.35em}
\begin{stepbox}{Why ``fake''}
The people and apps exist only inside AppWorld. The accounts and payments are not a real phone or a real Venmo.
\end{stepbox}
\end{column}
\end{columns}
\end{frame}

\begin{frame}
\begin{center}
  {\Large\bfseries\color{deepblue} Two kinds of Python}\\[2pt]
  {\color{accent}\rule{0.32\linewidth}{1.1pt}}
\end{center}

\vspace{0.55em}
\begin{columns}[T]
\begin{column}{0.49\textwidth}
\begin{stepbox}{Already in the apps}
\raggedright
The 457 functions are written in advance. The language model does not write them.

\vspace{0.4em}
One of them is \texttt{apis.venmo.show\_transactions}, which lists payments.
\end{stepbox}
\end{column}
\begin{column}{0.49\textwidth}
\begin{stepbox}{Written while the task runs}
\raggedright
The language model writes Python that calls those functions. For example:

\vspace{0.45em}
{\scriptsize\texttt{apis.phone.search\_contacts(...)}}\\[2pt]
{\scriptsize\texttt{apis.venmo.show\_transactions(...)}}
\end{stepbox}
\end{column}
\end{columns}
\end{frame}

\begin{frame}
\begin{center}
  {\Large\bfseries\color{deepblue} An example of a task}\\[2pt]
  {\color{accent}\rule{0.36\linewidth}{1.1pt}}
\end{center}

\vspace{0.25em}
\begin{plainbox}
\textit{How much money have I sent to my roommates on Venmo since January 1?}
\end{plainbox}

\vspace{0.35em}
The model writes Python that calls the apps. For this task it looks like this:

\vspace{0.2em}
\begin{codebox}
roommates = apis.phone.search\_contacts(\\
\hspace*{1.5em}access\_token=phone\_access\_token,\\
\hspace*{1.5em}relationship="roommate")\\
payments = apis.venmo.show\_transactions(\\
\hspace*{1.5em}access\_token=venmo\_access\_token)
\end{codebox}

\vspace{0.2em}
\begin{stepbox}{How a task is scored}
AppWorld runs the tests that came with the task. The task passes when every test passes.
\end{stepbox}
\end{frame}
